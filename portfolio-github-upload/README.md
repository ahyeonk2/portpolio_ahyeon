# KWON AHYEON Portfolio

관리자 로그인이나 서버 없이 동작하는 정적 포트폴리오입니다. 현재 공개 콘텐츠와 이미지는 `content.js`에 고정되어 있어 첫 접속부터 동일하게 표시됩니다.

## 로컬에서 보기

`index.html`을 브라우저로 열거나 정적 파일 서버를 사용합니다.

```sh
python3 -m http.server 8000
```

그다음 `http://127.0.0.1:8000`에 접속합니다.

## 배포

`main` 브랜치에 올리면 `.github/workflows/pages.yml`이 GitHub Pages에 자동 배포합니다. Python 서버, Render, 데이터베이스 설정은 필요하지 않습니다.

## 콘텐츠 수정

사이트에 표시되는 소개, 프로젝트, 이미지, 연락처는 `content.js`에 들어 있습니다. 내용을 수정한 뒤 GitHub에 다시 올리면 배포된 사이트에도 반영됩니다.

방명록은 방문자 각자의 브라우저에만 저장되며 다른 기기나 방문자에게 공유되지 않습니다.
